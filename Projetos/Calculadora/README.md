Durante o curso de Desenvolvimento Web da Udemy, desenvolvi uma calculadora simples utilizando HTML, CSS e JavaScript. O objetivo do projeto foi colocar em prática o que eu estava aprendendo, principalmente sobre funções, eventos e manipulação dos elementos da página com JavaScript.
Foi um projeto relativamente simples, mas que me ajudou bastante a entender como o JavaScript funciona junto com o HTML e o CSS. Durante o desenvolvimento, fui criando a lógica das operações e entendendo melhor como pegar os valores digitados pelo usuário, realizar os cálculos e mostrar o resultado na tela.
