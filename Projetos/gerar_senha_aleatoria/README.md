Lógica:

Uma boa opção para hoje é um Gerador de Senhas Aleatórias:

A ideia é esta: você terá um campo onde a pessoa escolhe o tamanho da senha, por exemplo 8, 12 ou 16. Depois clica em Gerar senha. O JavaScript pega caracteres aleatórios de uma lista como:

1. Criar um input para informar o tamanho da senha.
2. Criar um botão "Gerar senha".
3. Criar um lugar na tela para mostrar a senha.
4. Quando clicar no botão:
      pegar o valor do input
5. Criar uma variável com todos os caracteres possíveis.
6. Criar uma variável vazia:
7. Criar um FOR que repita de acordo com
   o tamanho escolhido pelo usuário.
8. Dentro do FOR:
      gerar uma posição aleatória
9. Usar essa posição para pegar
   um caractere da lista.
10. Adicionar esse caractere na variável senha.
11. Depois do FOR:
      mostrar a senha na tela.
